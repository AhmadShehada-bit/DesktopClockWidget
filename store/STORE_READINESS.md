# Microsoft Store Submission Readiness Package

> **Status**: STORE PACKAGE READY — SUBMISSION REQUIRES PARTNER CENTER ACCESS

This directory contains the packaging specifications, assets, manifests, and listings required to publish **DesktopClock Widget** to the Microsoft Store via the Microsoft Partner Center.

---

## 1. App Identity
- **Package Name**: `AhmadShehada.DesktopClockWidget`
- **Publisher**: `CN=AhmadShehada`
- **Target OS**: Windows 10 Version 1809 (Build 17763.0) or higher (Windows 10 / Windows 11)
- **Architecture**: `x86` / `Neutral` (runs on all x86, x64, and ARM64 via emulation)
- **Capabilities**:
  - `runFullTrust` (Desktop Bridge execution)
  - `internetClient` (Optional weather forecasts)

---

## 2. Listing Metadata
- **Title**: DesktopClock Widget
- **Short Description**: Lightweight, customizable Windows desktop clock with curated aesthetic themes, weather, metrics, and world timezones.
- **Category**: Productivity / Personalization
- **Pricing**: Free / Open Source (MIT)
- **Content Rating**: All Ages (ESRB Everyone / PEGI 3)

---

## 3. Partner Center Submission Steps
1. Log in to [Microsoft Partner Center](https://partner.microsoft.com/dashboard).
2. Create a new app submission for `DesktopClock Widget`.
3. Link the package identity from `msix/AppxManifest.xml`.
4. Upload the MSIX package generated by `scripts/package_msix.bat`.
5. Provide store listing text and screenshots from `store/listing/` and `assets/github/`.
6. Link `PRIVACY.md` in the privacy policy URL field.
7. Submit for certification.
